APK Drop

ลากไฟล์ APK มาวาง แล้วติดตั้งลงโทรศัพท์ผ่านสาย USB ไม่ต้องพิมพ์คำสั่ง

เบราว์เซอร์นี้ใช้ไม่ได้เปิดไฟล์นี้ด้วย Google Chrome หรือ Microsoft Edge บนคอมพิวเตอร์ (Firefox และ Safari ไม่รองรับการต่อ USB จากหน้าเว็บ)
1

เตรียมโทรศัพท์

เปิด USB debugging ทำครั้งเดียวต่อเครื่อง
  1. เปิดแอป การตั้งค่า → เกี่ยวกับโทรศัพท์
  2. แตะ หมายเลขบิลด์ (หรือเลขที่เวอร์ชัน) 7 ครั้งติดกัน
  3. กลับไปหน้าการตั้งค่า เข้า ตัวเลือกสำหรับนักพัฒนา
  4. เปิด การแก้ไขข้อบกพร่อง USB (USB debugging)
  5. เสียบสาย USB เข้าคอมพิวเตอร์ เลือกโหมด การถ่ายโอนไฟล์
2

เชื่อมต่อโทรศัพท์

ยังไม่ได้เชื่อมต่อ
เสียบสาย USB แล้วกดปุ่มเพื่อเลือกโทรศัพท์
3

ลากไฟล์ APK มาวาง

วางไฟล์ .apk ตรงไหนของหน้านี้ก็ได้
หรือกดเพื่อเลือกไฟล์ เลือกได้หลายไฟล์พร้อมกัน

    บันทึกการทำงาน

    ติดตั้งเสร็จแล้วควรปิด USB debugging เพื่อความปลอดภัย ไฟล์ APK ถูกส่งจากคอมพิวเตอร์ไปที่โทรศัพท์โดยตรง ไม่ผ่านอินเทอร์เน็ต
